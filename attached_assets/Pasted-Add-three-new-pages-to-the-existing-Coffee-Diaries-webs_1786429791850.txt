==================================================

Large decorative stamp containing:

Country flag
Country name
VISITED

Locked country:

Muted appearance

Lock icon

"Not yet explored"

Do not make locked cards overly dark or visually harsh.

==================================================
UNLOCK LOGIC
==================================================

When a user explores a coffee:

1. Identify the coffee's country.
2. Check whether that country has already been unlocked.
3. If not unlocked:
   - Add country to Passport
   - Display a subtle "Passport Stamp Added" notification
   - Animate the new stamp
4. Update passport progress.

For now, this can use localStorage if authentication/backend does not yet exist.

Structure the code so it can later be connected to a database.
