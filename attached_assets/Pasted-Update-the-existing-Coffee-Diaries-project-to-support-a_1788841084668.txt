Update the existing Coffee Diaries project to support a simple QR-based on-table ordering system.

IMPORTANT:
Only make the changes described below. Do not redesign or rebuild the existing website. Keep all current pages, features, styling, animations, and components.

ORDERING CONCEPT:
- Each café table has its own QR code.
- Scanning the QR automatically identifies the table.
- Multiple people can scan the same table QR.
- Each person places their own order independently.
- Each person receives their own individual bill.
- No user account/login is required for ordering.
- The customer only enters their name and phone number.

1. TABLE QR FLOW

QR Code
→ Identify Table
→ Enter Name + Phone Number
→ Start Ordering

Example:
Table 12 QR → /order?table=12

After scanning, show:

"Welcome to Coffee Diaries"
"You're ordering from Table 12"

Name: [________]
Phone: [________]

[Start Ordering]

Do not ask the customer to manually select a table.

2. PERSONAL ORDER

Each customer should have their own:
- Cart
- Order
- Bill

Multiple customers at the same table must NOT share the same cart or order.

Example:

Table 12
├── Customer A → Order #101 → ₹280
├── Customer B → Order #102 → ₹180
└── Customer C → Order #103 → ₹260
